# U39 — 3대 도구 토큰예산 절약과 Ollama→Antigravity 승격 규칙

상태: Codex 보조·감사 제안. Claude 주도자가 검토·편입하기 전에는 전역 정본이 아니다.

## 목표

Codex·Claude·Antigravity의 유료/제한 토큰은 계약 작성, 판단, 독립검증에 집중한다. Ollama는 좁은 기계 작업을 먼저 계산하되, 못하는 작업을 반복해서 붙잡지 않는다. 품질은 동일한 고정 인수로 판정한다.

## 단일 경로

1. **결정적 도구 우선**: 검색, 해시, diff, 테스트, 정형 추출로 끝나면 모델을 호출하지 않는다.
2. **Ollama 1회**: 구체성 80점 이상, 판단 불필요, 출력 스키마와 고정 인수가 있는 작업만 맡긴다.
3. **실패 분류**:
   - `FORMAT_ONLY`: 내용 근거가 모두 맞고 형식만 틀림. 남은 로컬 예산 안에서 더 좁은 프롬프트로 1회만 재시도한다.
   - `SEMANTIC`, `UNSUPPORTED`, `SCOPE`, `TOOL_LIMIT`, `JUDGMENT_REQUIRED`: Ollama를 즉시 중단하고 Antigravity 후보로 승격한다.
4. **Antigravity 1회**: B85 비용관문이 `WITHIN`을 강제하고, 매뉴얼·고정 인수·허용 파일·중지조건이 있을 때만 실행한다.
5. **독립판정 1회**: 원래 조율자인 Codex 또는 Claude가 diff·고정 인수·사용량을 판정한다. 작업자 자기보고는 증거가 아니다.
6. **원격도 실패하면 재설계**: Ollama로 되돌려 반복하지 않는다. 작업 범위를 나누고 새 work_id를 만든다.

## 기본 예산

- Ollama: 작업 전체 합계 12,000 로컬 토큰, 120초, 정상 1회. 형식만 실패했을 때만 합계 안에서 1회 추가한다.
  - 근거: 현재 검증된 로컬 PASS P08은 10,031토큰이다. 20% 여유를 더해 약 12,000으로 잡는다.
  - U38은 1,073토큰·22.9초에 형식과 의미분류를 함께 실패했으므로 재시도 없이 승격 대상이다.
- Antigravity: 작업별 `remote_budget_tokens` 필수, 기본 상한 120,000 총토큰, 원격 시도 1회.
  - 근거: 기존 U36 계약의 120,000을 임시 상한으로 유지한다. 이는 최적값이 아니라 검증 전 안전상한이다.
  - 예상량이 120,000을 넘으면 실행하지 않고 작업을 분할한다.
  - B85 수정 전에는 이 상한이 직접 작업자에게 적용되지 않으므로 모든 새 원격 실행을 차단한다.
- Codex·Claude: work_id당 기본 개입 2회(계약·최종판정). 중간 기계 편집과 반복 요약을 직접 수행하지 않는다.
- 같은 작업을 두 작업자에게 동시에 보내지 않는다. 순차 승격만 허용한다.

## 승격표

| 관찰 | 다음 행동 |
|---|---|
| 결정적 명령으로 해결 가능 | 모델 호출 없음 |
| Ollama PASS + 고정 인수 PASS | 독립판정 후 종료 |
| Ollama 형식만 실패 | 남은 로컬 예산 안에서 1회 축소 재시도 |
| Ollama 의미·근거·범위·도구 실패 | Antigravity 1회 승격 |
| 설계·탐색·다중파일 판단 작업 | Ollama를 건너뛰고 Antigravity |
| Antigravity 비용관문 UNKNOWN/EXCEEDED | 반영 금지, 작업 분할 |
| Antigravity도 인수 실패 | 조율자가 원인 분석 후 새 계약; 자동 재시도 없음 |

## 측정식

- `총 작업토큰 = Ollama 입력+출력 + Antigravity 입력+출력 + 조율자 계약·판정 토큰`
- `재작업률 = 인수 실패 또는 REWORK 작업 수 / 전체 작업 수`
- `승격효율 = Ollama 실패 뒤 Antigravity가 첫 시도에 인수를 통과한 수 / Ollama→Antigravity 승격 수`
- `조율자 절감 = 직접 수행 기준 토큰 - 계약·판정 토큰`. 동일 과제 대조군이 없으면 `UNMEASURED`다.
- 10개 유효 작업마다 경로별 통과율·재작업률·토큰·시간을 비교한다. 품질 저하 또는 3배 비용 회귀면 해당 경로를 채택하지 않는다.

## 현재 판정

- U38 Ollama 출력: `SEMANTIC + FORMAT`, 즉시 승격 대상.
- Antigravity 실행: `BLOCKED_B85`. 직접 worker=agy 예산을 무시한 채 U36에서 655,207토큰을 사용했으므로 B85가 통과하기 전에는 실행하지 않는다.
- B85 통과 후 첫 원격 과제: U38 설계의 독립 반례검토. 원격 1회, 총토큰 상한 120,000, 수정 권한 없음, 판정자는 Codex다.
