## 한 줄 요약

**비싼 AI(Codex·Antigravity·Claude Code)가 할 필요 없는 일을 이 PC의 무료 AI(Ollama)에 넘겨, 계정 한도가 바닥나도 멈추지 않고, 비싼 AI가 읽는 양은 약 86% 줄였습니다.**

## 왜 했나 (목적)

1. **멈추지 않기.** 2026-09-20, 원격 도구 셋의 사용 한도가 모두 바닥나 작업이 멈췄습니다(Codex는 9/24까지). 로컬 모델은 한도가 없습니다.
2. **돈(토큰) 아끼기.** 로컬 모델은 이 PC에서 돌아가니 토큰 비용이 0입니다. 이 프로젝트의 이름이 "AI 환경 다이어트"인 이유와 같습니다 — 같은 결과를 더 적은 비용으로.
3. **약한 일꾼도 안전하게 쓰기.** 7B 모델(작은 AI)은 틀릴 수 있습니다. 그래서 "모델의 말"이 아니라 "관문(자동 검사)"이 합격을 정하게 했습니다. 틀리면 원본은 그대로이고 잃는 것은 시간뿐입니다.

비유: 비싼 전문가(원격 AI)에게 서류 정리까지 시키지 않고, 무료 인턴(로컬 AI)에게 정리·초안·찾기를 맡깁니다. 인턴의 결과는 전문가가 확인하고, 최종 결정은 전문가가 합니다.

## 지금 모습 — 누가 무엇을 하나

```
사용자 지시
   │
   ▼
Codex / Claude Code (지휘·판정)  ── 판단이 필요한 일, 최종 합격 판정
   │
   ├─ Antigravity (원격 작업자)   ── 모호하거나 큰 설계가 필요한 구현
   │
   └─ Ollama (로컬 작업자, 토큰 0) ── 구체적인 수정, 요약·초안·분류, 파일 찾기,
                                     큰 파일 읽기 전 줄 번호 요약본
```

세 도구는 지시가 없어도 스스로 판단해 로컬 모델을 먼저 씁니다(전역 규칙 v5.12.0). 기준은 하나입니다: **판단이 필요하면 비싼 AI, 정확히 적을 수 있거나 읽고 줄이는 일이면 로컬.** 판정은 절대 로컬에 맡기지 않습니다.

## 아직 모르는 것 (정직하게)

- **실제 세션 절감:** 요약본 경로 −85.9%는 한 번 읽기 기준의 통제된 비교입니다. 세 도구가 실제 작업 중 얼마를 아꼈는지는 `UNMEASURED`입니다.

- **독립 검토:** 이 작업 대부분은 Codex 부재 중 Claude Code가 대행했습니다. Codex 복귀 시 재검토 목록(`.coord/PLAN.md`)에 올라 있습니다.
