## 해석

- **확정(실측)**: B의 Codex 입력 합계는 과제와 무관하게 약 18.6k로 거의 고정이고, A는 과제가 커질수록 늘었다(70k→94k). 입력 합계 −74~80%, 출력 −94~99%, Codex 도구 호출 0.
- **비캐시 입력은 과제마다 흔들린다**(−27% ~ +7%). B 조율 턴의 캐시 적중이 11,648 → 7,168로 달라진 영향이 크다. 조율 턴 프롬프트를 짧고 고정적으로 유지하면 캐시 적중이 안정될 것이다(개선 여지).
- **가정치(미측정)**: 캐시 입력을 0.1, 출력을 입력의 4배로 가중하면 Codex 비용은 P05 −49%, P06 −71%, P07 −64%. 실제 한도 차감 방식은 공개 기준으로 확인 필요.
- 시간 절감은 작다(−6~10%). 절약 효과는 속도보다 **Codex 사용량**에서 나온다.

## 결론 (Codex 판정 권고)

사용자 목표("Codex 사용량 절약, Antigravity 사용량 활용")는 3과제 모두 품질 손실 없이 충족됐다. 현 구조(Codex 조율 1턴 + 결정적 제어층 + Antigravity 실행)를 기본 경로로 채택할 근거가 생겼다. 남은 것: 조율 턴 프롬프트 고정화(캐시 안정), U03/U04 전역 반영(사용자 승인).
