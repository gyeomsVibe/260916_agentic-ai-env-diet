# Claude Code ↔ Antigravity 64: 3대 도구 글로벌 규칙 개정 사용자 지시 전달 (2026-09-20)

윤겸스(사용자)께서 **3대 도구 글로벌 룰 개정 및 무승인 논스톱 실행 정착**에 관한 확정 지시를 내리셨습니다.
본 메모를 확인하고 Claude Code, Codex, Antigravity 3대 도구 환경의 전역 규칙 개정을 무승인 논스톱으로 진행해 주시기 바랍니다.

## 1. 사용자 확정 지시 핵심 요건

1. **"추천" 섹션 및 관련 문구 전면 영구 삭제**:
   - 글로벌 룰에서 `**추천**` 출력 정의 및 관련 지침을 완전히 제거한다.
   - **주의**: "추천안을 쓰지 않는다", "추천을 제외한다" 등 추천에 관한 금지/메타 문구 자체도 규칙에 일절 작성하지 않는다 (부정 프롬프팅 및 토큰 낭비 방지).
   - 에이전트 출력 형식은 순수하게 **결과**(핵심 1~3줄, 변화 없으면 1줄) 하나로만 단일화한다.

2. **개정 배경 (사용자 UX 및 에이전트 프로세스 병목 해소)**:
   - 추천안을 출력하면 사용자 UX상 다음 행동을 알 수 있어 좋으나, 3대 도구 프로세스가 "무승인 논스톱" 원칙임에도 불구하고 `추천` 항목을 생성하는 순간 승인 대기 관문(approval gate)으로 오인하여 스스로 멈추고 다음 단계로 진행하지 않는 현상이 반복됨.
   - 따라서 추천 항목 자체를 없애고, 계획된 다음 단계는 멈춤 없이 같은 턴에 즉각 선구현/실행하도록 프로세스를 강제함.

3. **기사 분석 2종 인사이트 반영 (출력 및 실행 원칙)**:
   - **기사 1 ([아직도 코드를 읽나요?](https://share.google/mI7fwJBqWR7ASRe8E))**:
     - 코드를 읽는 수고를 사용자에게 넘기지 않고 에이전트가 도메인 모델과 요구사항 이해를 완벽히 유지한 채 구현을 책임진다.
     - 장황한 설명, 코드 나열, 중간 과정 해설은 전면 배제하고, 핵심 도메인 요약과 완결된 결과만 사용자 대화창에 출력한다.
   - **기사 2 ([GeekNews Ask: 코딩 에이전트를 어디까지 믿고 맡기는가?](https://news.hada.io/topic?id=33727))**:
     - 에이전트 방치나 과신을 방지하기 위해 엄격한 검증 테스트(fail-closed)를 전제로 하되, 사소한 단계마다 질문하거나 추천을 던지며 멈추는 "승인 피로"를 원천 차단한다.
     - 실패 없는 명확한 범위는 멈춤 없이 논스톱으로 완결하고, 검증 통과 여부와 핵심 결과만 1~3줄로 보고한다.
