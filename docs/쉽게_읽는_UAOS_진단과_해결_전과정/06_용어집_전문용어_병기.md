# 06. 용어집 — 전문용어 병기

- 표기는 "한국어(영어)"다. "비유" 칸은 사용자의 5대 비유나 일상 비유다.
- "어디에" 칸은 이 저장소에서 그 개념이 사는 파일이다.

## 도구와 역할

| 용어 | 뜻 | 비유 | 어디에 |
|---|---|---|---|
| UAOS(Unified Agent Operating System) | AI 도구 넷이 한 팀으로 일하는 규칙과 프로그램 묶음 | 오케스트라 운영 규칙 | 저장소 전체 |
| 지휘자(commander) | 계획·판정·승인을 하는 도구. Codex | 지휘자 | `AGENTS.md` |
| 부지휘자(sub-commander) | Codex 부재 시 대행. Claude Code | 부지휘자 | `CLAUDE.md` |
| 작업자(worker) | 실제로 파일을 고치는 쪽. Antigravity·Ollama·apply | 연주자 | `v7_harness/adapters/` |
| 판정자(judge) | 결과를 받아들일지 정하는 사람·도구. 작업자와 달라야 함 | 심판 | 매뉴얼 `judge:` 칸 |
| 검증자(verifier) | 판정 전에 반례를 찾는 쪽. 작성자와 달라야 함 | 교차 채점자 | `v7_harness/rsi.py` |
| Ollama | 내 PC에서 도는 무료 로컬 모델. 시킨 계산만 함 | 전자계산기 | docs/30 |

## 작업 방식

| 용어 | 뜻 | 비유 | 어디에 |
|---|---|---|---|
| 파일럿(pilot) | 원본을 건드리지 않고 **격리 사본(staging)**에서 작업자를 돌려 보는 실행 | 리허설 | `v7_harness/pilot.py` |
| 번들(bundle) | 파일럿이 만든 변경 묶음. 판정자가 번들 ID로 승인하면 원본에 반영 | 결재 서류 | `pilot run --approve` |
| 계약 매뉴얼(contract manual) | 작업 지시서. 첫머리 ```contract 칸을 기계가 검사 | 계약서 | `v7_harness/manual.py`, `.coord/tasks/` |
| 인수 명령(acceptance command) | 결과가 맞는지 확인하는 명령. 보통 테스트 | 검수 | 매뉴얼 `acceptance:` |
| 받아쓰기 적용(apply worker) | 정답 코드가 지시서에 있으면 모델 없이 그대로 적용 | 복사기 | `v7_harness/adapters/apply_worker.py` |
| 출력 가드(output guard) | 문법 오류·요청 밖 삭제·범위 밖 변경을 거부 | 검문소 | `v7_harness/adapters/ollama_worker.py` |
| 허용 범위(allowed scope) | 작업자가 고쳐도 되는 파일 목록 | 출입 허가 구역 | 매뉴얼 `allow:` |
| 하네스(harness) | 작업자가 정해진 길로만 가게 하는 장치 전체 | 말의 마구 | docs/37 |
| 결정적(deterministic) | 같은 입력이면 항상 같은 결과. AI 판단이 아님 | 계산기 | 교환원·관문 |
| 구조화 출력(structured output) | 모델 출력 형식을 JSON 스키마로 강제 | 서식 정해진 답안지 | `olla_evidence.py` |
| 시드(seed) | 무작위성을 고정하는 숫자. 실패를 재현하게 해 줌 | 같은 순서로 섞은 카드 | `ollama_worker.py` |

## 연락과 감시

| 용어 | 뜻 | 비유 | 어디에 |
|---|---|---|---|
| 우편함(mailbox) | 도구끼리 남기는 메시지 저장소 | 음성사서함 | `v7_harness/coord/mailbox.py` |
| 임대(lease) | 메시지를 꺼낸 쪽이 처리할 시간. 넘기면 회수 | 도서 대출 기한 | `claim`·`renew` |
| 처리 확인(ack) / 되돌리기(nack) | 처리 끝 표시 / 못 해서 다시 넣기 | 수신 확인 / 반송 | mailbox |
| 최소 1회 배달(at-least-once) | 잃지 않되, 중복은 번호로 걸러냄 | 등기우편 | docs/36 §2-1 |
| 교환원(sentinel) | 60초마다 점검하고 급할 때만 벨을 울리는 결정적 프로그램. 모델 호출 0 | 24/7 교환원 | `v7_harness/coord/sentinel.py` |
| 벨(bell) | Codex에게 보내는 알림(`codex queue`) | 전화벨 | `ring_bell` |
| P1 | 가장 급한 등급. 멈춘 잠금, 정리 필요 작업, 차단된 작업 | 응급 호출 | sentinel |
| 출석부(presence) | 도구별 "지금 있음"과 만료 시각. 만료되면 UNKNOWN | 출근 카드 | `v7_harness/coord/presence.py` |
| 스트림(stream) | 도구들이 남기는 작업 기록 줄 | 공용 업무일지 | `.coord/stream/` |
| 훅(hook) | 도구가 특정 순간(세션 시작 등)에 자동 실행하는 명령 | 자동문 센서 | `.claude/settings.json`, docs/39 |
| 비둘기 퇴출 | 사람이 말을 옮기지 않아도 도구끼리 연락됨 | 전서구 대신 전화 | 출석부·스트림 |

## 측정과 개선

| 용어 | 뜻 | 비유 | 어디에 |
|---|---|---|---|
| 사용량 장부(usage ledger) | 실행마다 작업자·결과·토큰·실패 원인을 남기는 기록. 사용자 PC 전용이며 커밋하지 않음 | 가계부 | `.coord/usage/runs.jsonl` |
| 자가개선(RSI, Recursive Self-Improvement) | 기록을 보고 다음 실행을 더 낫게 하는 반복. UAOS에서는 매뉴얼·정책만 바뀜 | 오답 노트 | `v7_harness/rsi.py`, docs/31·38 |
| 증거 관문(evidence gate) | 장부로 전후를 다시 계산해 후보를 거르는 검사 | 감사(audit) | `rsi gate` |
| 목표 해킹·보상 해킹(objective/reward hacking) | 문제를 푸는 대신 채점을 속이는 것 | 채점표 고치는 학생 | docs/38 §2 |
| 굿하트의 법칙(Goodhart's law) | 지표가 목표가 되면 좋은 지표가 아니게 된다 | 조회수만 좇는 기사 | 다중 지표 검사 |
| 자기 선호 편향(self-preference bias) | AI가 자기 답을 더 높게 평가 | 자기 작품 심사 | 판정자 분리 |
| 창(window) | 분석 단위. 기본 10회 | 10경기 성적 | `policy.json` `window` |
| 톱니(ratchet) | 한 방향(더 엄격하게)으로만 움직이는 기준 | 톱니바퀴 | `POLICY_BOUNDS` |
| 되돌리기(rollback) | 채택한 변경을 이전 값으로 복원 | 실행 취소 | `rsi rollback` |
| 자가치유(self-healing) | 방치된 메시지 회수 같은 자동 복구. 테스트 수정은 제외 | 자동 차단기 복귀 | sentinel |
| 재현(reproduce) | 결함을 짧은 프로그램으로 실제로 일으킴 | 증상 재현 검사 | `.coord/runs/U31/metaphor_probe.py` |
| 회귀 검사(regression test) | 고친 뒤 다른 곳이 망가지지 않았나 전체를 다시 돌림 | 종합 검진 | `python -m unittest discover -s tests -t .` |
| 빨간 테스트 먼저(red-first) | 고치기 전 실패하는 테스트부터 작성 | 증상 확인 후 치료 | 모든 수정 |

## 설치와 배포

| 용어 | 뜻 | 비유 | 어디에 |
|---|---|---|---|
| 전역 규칙(global rules) | 모든 프로젝트에서 도구가 읽는 규칙 파일(`~/.claude/CLAUDE.md` 등) | 회사 전체 규정 | docs/39 |
| 정본(canon) | 전역 규칙의 원본. 생성기가 여기서 런타임 파일을 만듦 | 원본 문서 | `260718…/shared/global-rules` |
| 표류(drift) | 실행 중 파일이 정본·설치 상태와 달라진 것 | 원본과 다른 복사본 | `--check` |
| 미리보기(dry-run) | 실제로 쓰지 않고 무엇이 바뀔지만 보여 줌 | 견적서 | 설치기 기본 동작 |
| 실행기(launcher) | 어느 폴더에서나 UAOS를 실행하게 하는 작은 파일 | 바로가기 | `~/.uaos/uaos.py` |
| 작업 스케줄러(Task Scheduler) | Windows가 정해진 때(로그온 등)에 프로그램을 실행하는 기능 | 알람 | `--register-sentinel` |
| UNKNOWN / UNMEASURED | 확인 못 함 / 측정 안 함. 사실로 취급하지 않음 | "모름"이라고 적기 | 모든 문서 |
