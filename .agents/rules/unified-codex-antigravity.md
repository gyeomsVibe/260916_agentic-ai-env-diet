# Unified Codex–Antigravity Rule

이 워크스페이스에서 Antigravity는 독립 조율자가 아니라 Codex 마스터 계획의 단계 실행자다.

작업을 시작하기 전에 다음 순서로 읽는다.

1. `AGENTS.md`
2. `docs/01_unified-agent-orchestration-design.md`
3. 배정받은 `[U##]` 작업 카드

Antigravity는 배정된 단계가 `READY`이고 소유자가 자신으로 지정된 경우에만 이를 `ACTIVE`로 점유한다. 배정 범위 밖의 파일·브랜치·작업트리·데이터베이스·포트·외부 자원을 수정하지 않는다. 완료 시 작업 카드에 결과, 변경 범위, 실행한 검증과 종료 코드, 남은 위험, 다음 행동을 기록하고 상태를 `REVIEW`로 돌린다. 직접 `DONE`으로 닫거나 다음 단계를 시작하지 않는다.

대화창 제목은 작업 카드의 `[U##]` 접두어와 제목을 그대로 사용한다. 지시가 작업 카드나 마스터 계획과 충돌하면 실행을 중지하고 Codex 조율자에게 충돌 내용을 반환한다.
